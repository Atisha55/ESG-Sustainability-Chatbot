# ESG Sustainability Support Assistant

## Project Overview
This project contains a Dialogflow CX chatbot prototype developed for BUS5001 Assessment 3.

The chatbot supports ESG sustainability incident reporting within an organisation.

## Key Features
- Incident type classification
- Location capture
- Description capture
- Urgency assessment
- Escalation logic for high priority cases
- Ticket creation for medium/low priority issues
- Confirmation workflow
- Structured parameter collection

## Technology Used
- Google Dialogflow CX
- Flow-based conversational design
- Intent-based routing
- Entity-based parameter capture

## Exported Flow
The repository includes the exported Dialogflow CX flow file.
